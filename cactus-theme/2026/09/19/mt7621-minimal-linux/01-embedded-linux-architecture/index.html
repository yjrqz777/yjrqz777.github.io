结论速览

  • 最小系统就一条链：U-Boot 到 Kernel 到 initramfs/rootfs 到 /init 到 BusyBox 或自定义应用。
  • U-Boot 不是用户空间程序，bootm 是 U-Boot 命令，不是 Linux 命令。
  • ls、sh、wget 这些命令不由内核提供，内核只提供进程调度、内存管理、驱动、文件系统、TCP/IP 和系统调用。
  • Debian、OpenWrt、Ubuntu 不是另一种内核，差别只在用户空间那一套。
  • 分析问题的第一步是判断它属于哪一层，分层正确，问题就不会显得混在一起。

层级 主要职责
U-Boot 加载内核、设备树、rootfs/initramfs，并跳转到内核入口
Linux Kernel 管理 CPU、内存、中断、驱动、网络、文件系统
initramfs/rootfs 提供用户空间中的目录、程序、库、配置
/init 第一个用户空间进程，通常为 PID 1
BusyBox 提供 shell 和常用 Linux 命令
应用程序 调用 Linux API 完成功能
