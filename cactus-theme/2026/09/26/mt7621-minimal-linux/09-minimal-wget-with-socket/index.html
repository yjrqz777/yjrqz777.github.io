嵌入式

结论速览

  • 最小 wget 的流程是解析 URL、DNS、建立 TCP、发送 HTTP 请求、接收响应、去掉 Header、保存 Body。
  • DNS 通常不是简单的内核 syscall，由 libc resolver 配合网络 socket 完成，接口是 getaddrinfo()。
  • socket(AF_INET, SOCK_STREAM, 0) 里 AF_INET 是 IPv4、SOCK_STREAM 是 TCP，内核返回文件描述符。
  • connect() 背后的 ARP、SYN/ACK、重传、IP、Ethernet 全部由内核处理，应用不用自己实现 TCP。
  • HTTP Header 与 Body 用 \r\n\r\n 分隔；HTTPS 多一层 TLS，涉及证书、密钥交换、握手，学习阶段先用 HTTP 地址。
