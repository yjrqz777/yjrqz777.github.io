结论速览

  • 头文件和 libc 里有声明只说明 API 存在，不代表 Kernel 支持该功能；能编译不等于运行时可用。
  • 网络功能要 Kernel 打开 CONFIG_NET、CONFIG_INET，还要有 MT7621 Ethernet Driver、MDIO、PHY Driver，链上任何一层缺失都不通。
  • /dev/ttyS0 需要 serial core、UART driver、设备树匹配、设备节点齐备才会出现。
  • rootfs 用 ext4、UBIFS 还是别的格式，Kernel 必须对应支持，否则无法挂载。
  • 常见启动问题未必是驱动代码有错，更多是 DTS 地址、中断、时钟、compatible 不匹配或 status = "disabled"。
  • 应用功能失败时按「应用 API、libc、Kernel 功能、驱动、设备树、硬件」逐层排查，比直接怀疑应用代码高效。
